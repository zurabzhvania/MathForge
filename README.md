# Calgo

A learning-focused numerical-computing toolkit for calculus, linear algebra,
numerical methods, and statistics. The console interface is C++, while
reusable mathematical modules can be implemented in C. Every implementation
is original, documented, tested, and accompanied by small runnable examples.

## First milestone

Build dependable numerical-calculus algorithms and a C linear-algebra core:
differentiation, integration, root finding, approximation, matrices, and
linear-system solving.

## Build and run

```sh
cmake -S . -B build
cmake --build build
./build/calgo_intro
```
